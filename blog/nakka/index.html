Introduction

Nakka is a fun, traditional Nepali board game that brings nostalgic memories of childhood. The game involves strategy, luck, and timing — and is deeply rooted in Nepali culture, often played with friends and family for entertainment. The digital version aims to revive that same cultural essence while offering an easy and accessible way to play on mobile devices.

Why This Version?

Nakka is more than just a casual game — it represents the cultural charm of Nepal. This project was built with the goal of modernizing a traditional experience for the digital age. After observing user interest in cultural games on platforms like APKPure and Play Store, it was clear that people were searching for nostalgic yet refreshing entertainment.

  • Simple and nostalgic gameplay
  • Offline mode support
  • Designed for all age groups
  • Preserves traditional Nepali look and feel

Key Features

  • Classic Nepali board gameplay
  • Offline play without internet
  • Lightweight and optimized for all devices
  • Interactive and colorful traditional design
  • Dark mode and modern UI features

Development Notes

Built using the Godot Engine — an open-source platform — Nakka focuses on performance and nostalgia. The design was prototyped in Figma with inspiration from Nepali art and board patterns. Similar to the 2048 project, this one also emphasizes a smooth, responsive experience on low-end devices.

What started as a fun side experiment became a full mobile game project that highlights the spirit of Nepali traditional games.

What's Next?

The game is archived for now so there won't be any updates but if I were to continue development, I'd focus on adding designs as follows:

  • Multiplayer mode
  • Leaderboard integration
  • Additional local game variations
  • New board themes inspired by Nepali festivals
