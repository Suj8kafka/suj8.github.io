An early connection between design and build

This project introduced me to the process of designing and building a larger web application. I used Figma for the interface direction, then worked with HTML, CSS, and Flowbite components as part of the front-end build.

The broader project used Node.js, TypeORM, and SQLite. That exposure helped me understand how interface decisions connect to the application behind them.

Why it belongs in the notebook

My work has since moved towards UI/UX and visual design. This school project remains part of that story: an early chance to think about an application as a connected experience rather than a collection of isolated screens.

The repository is the place to explore the original implementation. This is a short project note based on the existing portfolio description, rather than a claim of a production booking service.
