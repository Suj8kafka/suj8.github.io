Usage analytics, open to everyone

This portfolio uses a small analytics service built on Cloudflare Workers and D1. When connected, it counts page loads, sections reached, and clicks on projects, articles, resume, email, social and notebook links, skill details and theme choices. A click count shows intent; it does not confirm that a download finished or an email was sent.

It also measures estimated active time per page and section, and whether the portfolio reached 25%, 50%, 75% or the bottom of its scrollable distance. Time is counted while the page is visible and focused, pauses after 60 seconds without input or scrolling, and skips long browser-suspension gaps. It starts after the welcome overlay closes. This estimates foreground activity rather than attention or actual reading.

Time is sent in small batches, approximately every 15 seconds and on tab changes or departure, and added to daily counters. Only elapsed milliseconds and fixed section labels are included. Input events refresh an inactivity timer without recording keys, text or pointer coordinates in these analytics. One page load is limited to one hour of estimated active time and 240 timing reports. Closing a browser can prevent the last report from arriving.

Page loads are grouped by public page, referral source, browser family, device type and approximate country. Referral sources are stored as broad categories such as Google or LinkedIn; unrecognised sites are grouped as “Other websites”. URL queries, campaign tags, fragments and referral paths are not stored.

The service immediately adds to daily counters. It does not store individual event histories, raw IP addresses, full browser identifiers, names, email addresses, form contents or persistent visitor IDs in the analytics database. Counts are public on this page. It does not record sessions, screenshots or keystrokes.

This usage tracker sets no cookies and uses no browser storage. It respects Do Not Track and Global Privacy Control signals. Those signals apply to the usage tracker; essential hosting, security processing and the separate live presence feature still operate.

Separately, the maintained website pages load the Google tag for Google Analytics. Google Analytics may use first-party cookies such as _ga, a pseudonymous client identifier, page and referral details, device or browser information, and interaction data. Google receives the network address needed to process each request and states that Analytics does not log or store IP addresses. Google Analytics reporting is private to the site owner and is not included in the public dashboard above.

AI portfolio assistant

The optional portfolio assistant sends each question to a dedicated Cloudflare Worker. The Worker retrieves a small set of verified portfolio notes from Cloudflare D1 and asks Cloudflare Workers AI to create a concise answer. Do not enter confidential or sensitive information in the chat.

The site does not send earlier messages with a new question, and the Worker does not write questions, answers or conversation histories to D1. Messages remain only in the open page until it is reloaded. The selected Workers AI model is marked by Cloudflare as supporting zero data retention; Cloudflare still processes the request and network information needed to deliver and secure the service.

A random identifier is saved in this browser and sent with assistant requests so Cloudflare’s rate-limit service can limit repeated use. It is not added to the portfolio knowledge or public analytics tables and can be removed by clearing this site’s browser data.

Live presence, cursors & location

The portfolio’s live studio uses Firebase anonymous sign-in with an identity held in memory for each page. It shares a temporary visitor label, current section and path, approximate country, activity time and, when enabled, section-relative cursor coordinates with other connected visitors. This is separate from the daily usage counters above.

An approximate country lookup sends a request to ipwho.is, which receives your network address. Selecting “Use my precise location” asks for browser permission and sends your coordinates to BigDataCloud to resolve a city or locality. The site shares the resulting location label in live presence; it does not save the coordinates in Firebase.

You can turn cursor sharing and display off in the live studio panel. Reduced-motion settings also disable cursors. Precise location is optional and can be revoked in your browser settings. Presence records are scheduled for removal when a connection closes; stale records are hidden after about two minutes. Disconnection and cleanup can be delayed.

What stays in your browser

Your display preferences are saved locally so the site can remember Monochrome, Original, Dark or System themes alongside reading and motion choices. The welcome animation stores a seen flag in local and session storage so it does not repeat unnecessarily. The portfolio assistant stores a random rate-limit identifier. These browser values are separate from public analytics and can be removed by clearing this site’s browser data.

The owner’s login page uses Firebase authentication to manage availability. Login credentials and owner access are not part of this public analytics dashboard.

Services, security & retention

GitHub Pages hosts the portfolio. Cloudflare handles edge delivery, security, aggregate traffic estimates, the assistant’s portfolio knowledge, rate limiting and AI inference. Firebase handles live presence and availability. Google provides the separate private Analytics report. These providers receive the network information needed to serve requests and operate under their own policies. The site’s public analytics database does not store raw IP addresses; infrastructure providers may process them for delivery and security.

Daily usage counters are retained for up to 90 UTC calendar days. A scheduled daily job combines older counters into monthly aggregates, which have no automatic expiry and preserve All Time totals and breakdowns. The dashboard offers All Time, today, seven-day and thirty-day views; All Time charts show monthly totals. The older Firebase country counter is a separate cumulative count with no automatic expiry. Cloudflare traffic-history retention is managed separately by Cloudflare.

The portfolio owner does not sell visitor data. The custom public counters are not used for advertising profiles. Google Analytics data is processed according to the property’s Google settings and Google’s terms. Links to external projects and social networks take you to services with their own privacy practices.
