# Sujeet Khadka's portfolio

A portfolio of UI/UX and product design work by Sujeet Khadka, based in Lalitpur, Nepal.

Visit **[www.sujeetkhadka.com.np](https://www.sujeetkhadka.com.np/)** to explore selected projects, design experience and ways to get in touch. The [project notebook](https://www.sujeetkhadka.com.np/blog/) includes case studies and notes on designing mobile products, games and small web experiences.

The site includes display and reading preferences, an optional portfolio assistant, approximate live visitor activity and a public analytics report. Its core content and links remain readable when optional enhancements are unavailable. The owner updates work availability through `/login/`.

## Working on the site

The site uses plain HTML, CSS and browser JavaScript, hosted on GitHub Pages. Firebase supports availability and live presence; separate Cloudflare Workers support analytics, the assistant, security headers and the prepared old-blog redirect.

- **Developers:** start with [development and local setup](docs/development.md).
- **Agents:** read [AGENTS.md](AGENTS.md), then choose the relevant [task guide](docs/README.md).
- **Project owner:** see [known status and remaining work](docs/status.md), [publishing](docs/operations/deployment.md) and [search visibility](docs/operations/seo.md).
- **Past decisions and measurements:** consult the [history index](docs/history/README.md) when needed.

Local code, published site files and activated cloud services have separate verification records. A successful test run or Git push alone does not confirm live service health.
