Locally served Latin WOFF2 subsets of DM Mono (400 and 500), DM Sans (400–700) and Space Grotesk (500–700), downloaded from Google Fonts on 2026-11-09. DM Sans and Space Grotesk use one variable font file each. The font binaries are unmodified; each family's SIL Open Font License is included alongside them.

`scripts/fetch-portfolio-fonts.mjs` records the pinned distribution URLs and corresponding upstream license URLs. Run it from the repository root to restore these assets; network access is required. It validates WOFF2 headers and prints SHA-256 checksums. Space Grotesk is the only preloaded font; its `font-display: swap` declaration lives in `assets/css/site.css` and the generated inline critical CSS. DM Sans and DM Mono live in `assets/css/secondary-fonts.css` with `font-display: optional`. They load after full styling on desktop and direct section links, or on the first phone scroll. There is no Google Fonts stylesheet request. The no-JavaScript fallback loads both stylesheets normally.

The welcome's Namaste is local SVG artwork and needs no downloadable font. Unused Noto language-family requests were removed from the homepage.
