# Selected-work image sources

`esewa-redesign.webp` is Sujeet Khadka's published eSewa homepage redesign,
from [his case study](https://medium.com/design-bootcamp/improving-esewas-user-experience-reducing-accidental-top-ups-fixing-home-screen-clutter-6a7c7afc0c70).
The article's caption identifies it as “Redesigned Esewa’s homepage.”
The original image URL was retrieved from the author's public
[Medium RSS feed](https://medium.com/feed/@sujeetkhadka) on 2026-11-10:

https://cdn-images-1.medium.com/max/780/1*N1M8NWdNvnETW3a6uMbXSQ.png

The 780 × 1688 original was resized to 640 × 1385 and encoded as WebP at
quality 0.82 using browser canvas (42,198 bytes). The local file preserves the
full screen; the portfolio thumbnail crops from the top to highlight the
money actions and payment groups. No interface elements were redrawn.

The older `esewa-brand` files remain available, but the project card now uses
the actual redesign. Other images in this directory predate this pass.
