**Phone visits show a five-second welcome**, including repeat page loads. It cycles Hello, Hola, Bonjour, Ciao and Hallo, then ends with the existing handwritten Namaste. The first five greetings take 3570 ms, Namaste has 1250 ms for its drawing and readable hold, and the exit takes 180 ms: 5000 ms total once the animation starts. The greetings use the existing local heading font; Namaste uses local SVG artwork, with no new font download.

The mobile motion graphics use low-opacity color washes, drifting orbital linework and a moving dashed arc. Greeting changes use a short translation/fade without blur or rapid flashing. Skip intro, keyboard navigation and scroll intent dismiss it immediately. Reduced motion, save-data, direct section links and hidden tabs bypass it. The five-second fail-safe releases scrolling even when assets or animation frames stall.

Desktop first visits show a six-second welcome including the exit: Hello for 4720 ms, then animated Namaste for 1100 ms, then a 180 ms exit. Returning desktop visits show only animated Namaste. The same behavior is available at `/?intro=1`. Eligible welcomes request `loader/files/loader.css` dynamically and start after it loads; stylesheet error or a 2.5-second request stall leaves the page readable without locking scrolling. No-JavaScript pages hide the inactive markup.

The desktop preview shows the Sujeet wordmark, a stroke-written Namaste, and the progress bar. A returning preview lasts 1050 ms plus a 180 ms exit. Storage determines desktop duration; mobile always runs the complete five-second sequence. The original artwork and its stroke timing are unchanged.

`loader/files/namaste.svg` contains the local drawing artwork, also embedded in `#ld-namaste-template` in `index.html` to avoid an extra request. Its glyph outlines come from rendered Noto Sans Devanagari. Eighteen ordered pen paths draw the letter bodies, vowel mark, and finally their joining headline in 760 ms; a 120 ms ink finish preserves the complete letterforms. The completed word remains readable before dismissal. The drawing has no runtime font dependency.

Keep the SVG asset and inline template identical when editing the artwork. JavaScript inserts it only for Namaste and preserves plain text if the template is unavailable. Reduced motion disables the drawing, and a no-script style hides the welcome so the page remains usable.
