The active welcome is `loader/files/loader.js` and `loader/files/loader.css`.

**Normal homepage visits never show the welcome**, on desktop or mobile, including first visits and slow asset loads. The script immediately hides its inactive markup and emits `loader:done` once, before reading storage, awaiting fonts/portrait decoding, requesting intro CSS or locking scrolling. The page's original hero is visible immediately. The intro stylesheet is not requested by normal visits.

The artwork is preserved as an explicit preview at `/?intro=1`. On an unconstrained desktop with normal motion, that preview loads `loader/files/loader.css` dynamically and starts only once the stylesheet is available. A failed or stalled stylesheet leaves the page usable without a scroll lock. Phones/tablets up to 800px, coarse pointers, save-data, reduced motion and direct section links still bypass even an explicit preview.

The preview shows the Sujeet wordmark, a stroke-written Namaste, and the progress bar. A returning preview lasts 1050 ms plus a 180 ms exit. First previews last nine seconds in total: 7720 ms of Hello, 1100 ms of handwritten Namaste, and the 180 ms exit. Preview visits remember this state across sessions in local storage with a session-storage fallback; normal visits do not read or write it. Slow asset readiness is bounded, with a hard fail-safe. Scroll intent, navigation keys, and the skip control dismiss the preview immediately.

`loader/files/namaste.svg` contains the local drawing artwork, also embedded in `#ld-namaste-template` in `index.html` to avoid an extra request. Its glyph outlines come from rendered Noto Sans Devanagari. Eighteen ordered pen paths draw the letter bodies, vowel mark, and finally their joining headline in 760 ms; a 120 ms ink finish preserves the complete letterforms. The completed word remains readable before dismissal. The drawing has no runtime font dependency.

Keep the SVG asset and inline template identical when editing the artwork. JavaScript inserts it only for Namaste and preserves plain text if the template is unavailable. Reduced motion disables the drawing, and a no-script style hides the welcome so the page remains usable.
